{% load i18n tz %} {% comment %} The overview block, shared by the meeting, recording, conversation and alert panels so the four cannot drift apart. The violet treatment means "the model wrote this" — it is the one place the panel's palette breaks, which is what makes the break carry information. So editing does two things, not one: it changes the words, and it drops the claim. An overview a person has rewritten is drawn as ordinary panel content and says who wrote it. Expects panel_item.overview. The rest is optional: without .overview_edit_url the block is read-only, which is how the alert panel gets it — its "overview" is the alert description, written by whoever raised it, and never generated in the first place. The conversation panel's machine summary is read-only for a different reason: a navigator's words go in a second copy of this block, included with .human_block, rather than over the top of the model's. See ConvAI.conversation_summary. .overview_source_label overrides the "Generated " byline where the panel knows something more useful — a conversation summary can come from the agent that held it or from the classifier reading it afterwards, and which one wrote it is the first thing a navigator wants to know about it. Included more than once per panel, so nothing in here may use an id. {% endcomment %}
