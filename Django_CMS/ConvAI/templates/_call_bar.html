{% load i18n %} {% comment %} App-wide "a call is out" bar. The detail panel's own strip only exists while that panel is on screen, and the panel is deliberately easy to leave — the whole point of it is that you can go and read the client's history mid-call. Leaving it used to take the only evidence of the call with it. This bar carries the same stopwatch on every page. It renders empty and is filled in by script, because the call lives in sessionStorage rather than in the request: nothing server-side knows a call is in progress (there is no Twilio status callback — see the note in _detail_panel.html). {% endcomment %}
{% comment %} Two states, because a call that is still being placed is also a call in progress: leaving the panel during the Twilio round trip used to lose the only trace of it. The bar carries the dialling state through, in the same amber the button used, and swaps to the stopwatch once the call is out. {% endcomment %} {% trans "Call placed" %} 00:00 {% comment %} No End call here, deliberately. Ending is the moment the "how did it go?" question appears, and that lives in the panel — ending from the bar would leave the follow-up somewhere the navigator is not. It also keeps a button that does not actually hang up the phone off every page in the app. {% endcomment %} {% trans "Back to call" %}
