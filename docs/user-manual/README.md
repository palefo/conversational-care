# User manual (static site)

A task-oriented guide to the platform for care teams (navigators and admins).

- **Read it locally:** open [index.html](index.html) in a browser — no build
  step, no server needed.
- **Publish it:** the folder is plain static HTML/CSS. Serve it as-is with
  GitHub Pages, Netlify, nginx, or any static host.
- **Edit it:** each page is a self-contained HTML file sharing
  `assets/style.css`; edit the content inside `<main class="content">` and
  keep the sidebar links in sync across pages when adding a page.

The developer/operator documentation lives in
[docs/technical-manual.md](../technical-manual.md).
