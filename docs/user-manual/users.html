Users

Create and manage navigator and test-user accounts.

Admin

The Users page manages the accounts of your team. It is visible to admins only.

Account types you can create here

  • Navigator — a full account for a care team navigator. They see and manage their own clients only.
  • Test user — an account linked to one client, restricted to that client's audio chat. Only one test user per client. The generated username and password are shown once — copy them immediately (you can reset the password later by editing the user).

Admin accounts are created from the command line by the platform operator (see the technical manual).

Editing users

Open a user to change their name, e-mail, active status, preferred language, or password. Deactivating an account blocks sign-in without deleting history.
