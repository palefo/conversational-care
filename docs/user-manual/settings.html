Settings

Branding, integrations, models, prompts, self-registration and maintenance.

Admin

Settings configures how the platform behaves, connects and looks. Most values take effect immediately; a few marked Restart required are read from the server environment.

General & behaviour

  • Feature toggles that apply immediately: hide meeting steps, enable automations, enable self-registration, send care plans over WhatsApp, enable WhatsApp audio replies.
  • System values (timezone, async replies, debug mode, the Twilio webhook URL) are managed in the server's .env and shown here for reference.

Integrations & messaging

  • Integration credentials — Twilio account, platform phone number, OpenAI and ElevenLabs keys. Secrets are write-only: they are stored securely and never shown again; leave a field blank to keep the current value.
  • Messaging templates — SMS/WhatsApp sender numbers and the approved template identifiers used for reminders and alerts.

Branding

The name and logo shown across the app and on the login page. Upload a PNG, JPG or SVG (max 2 MB), or point at a static path.

Agents (models)

The default model behind in-process agents, per-provider API keys, and optional Azure routing. Values set here override the server's .env, so you can switch models or providers without redeploying.

Prompts

The base prompts used to summarise meeting protocols and call transcripts. Leave a field blank to use the built-in default — the relevant answers or transcript are appended automatically.

Registrations (self-registration)

Let people register themselves by scanning a QR code that opens WhatsApp with a pre-filled message:

  1. Turn self-registration on and pick the Self Registration Agent under General settings.
  2. Share the QR from this page (download it or copy the image); test the link yourself first.
  3. New registrants appear under Pre-registrations, waiting to be approved and assigned an agent — approve them to create the client.

A platform phone number must be configured for the WhatsApp link to be built.

API client

For teams that script the platform: this page shows whether the REST API is enabled, how to get a personal API token (Profile → API token), and download + install commands for the Python client package, pre-filled with your platform's address. Permissions through the API match the web app.

Maintenance

One-off background jobs you can trigger by hand: fetch new call recordings from Twilio, and classify conversations that have not been analysed yet.
