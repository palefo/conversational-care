The dashboard

Your day at a glance: what is pending, what needs review, and the call to make next.

The dashboard opens with a welcome and a one-line summary of your day: how many meetings are pending, how many of those are today, how many you have still to make, and how many chats are waiting to be reviewed.

It is a plain sentence, not a generated one. Every number in it is read from the same data as the box it describes, so the summary and the lists below can never disagree with each other.

What's on it

  • Next call — a card at the top showing the one call that most wants your attention: the oldest overdue one, or else the soonest due within the week. Open call opens it in the detail panel. The ✕ puts it away — you choose between just this call (the card returns with the next one, once this one is done or moved) and turning the card off for good, which you can undo under Profile → Home.
  • Chats to review — conversations the agent flagged as needing attention, each with the client and topic. Unread ones are in bold; opening one marks it read. Sort by priority, newest or oldest.
  • Pending meetings — what is still to be done, with the client, caregiver and scheduled time. Open one to run the call.
  • What changed this week — recent activity across your caseload, so handovers between colleagues are easy.
Tip
Everything on the dashboard opens in the same right-hand panel used on Communications — you never leave the dashboard to read something, and you come back to your place in the list.
Tip
Navigators see only their own clients everywhere — dashboard, calls, alerts. Admins see the whole organisation. If a client you expect is missing, check with your admin that you are set as that client's navigator.
