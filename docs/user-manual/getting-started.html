Getting started

Sign in, find your way around, and set the interface up for you.

Signing in

  1. Open your organisation's platform address in a browser and enter the username and password you received.
  2. Where you land depends on your role: navigators and admins go to the Dashboard; test users go straight to the audio chat of their linked client.
  3. To finish a session, open Profile (left menu) and use Log out.
Note
There is no self-service password reset yet. If you lose your password, ask your admin to set a new one from the Users page.

The layout

Everything hangs off the left sidebar (collapsible with the ☰ toggle):

  • Home — the dashboard.
  • Clients — your caseload.
  • Calls and Calendar — scheduled phone appointments.
  • Alerts — conversations escalated for review.
  • Users, Agents, Settings — admin-only configuration.
  • Help — your organisation's own guidance page.
  • Profile — your account, language, and API token.

A chat bubble in the corner opens the navigator assistant — a built-in AI helper that can look up clients and schedule meetings for you.

Your profile

  • Personal information — update how your name appears across the platform (your username itself cannot be changed here).
  • Language — the interface is available in English, Spanish, Portuguese, Italian, Korean and Simplified Chinese. Pick yours, or keep the system default chosen by your organisation.
  • API token — only needed if you script the platform with the Python client. The token is shown once when generated; regenerating it revokes the previous one. See Settings → API client.
