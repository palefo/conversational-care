Calls

Schedule, run and document structured phone calls, with recordings, transcripts and summaries.

Calls live in Communications, alongside everything else that passes between your team and a client. Scheduled calls sit under Coming up; finished ones move to Happened. Clicking one opens it in the detail panel, where you run it and write it up without leaving the list.

Scheduling

Create appointments from Schedule on Communications, from the Calendar, or by asking the navigator assistant. Pick the client, whether it is a phone call or an in-person meeting (and if in person, where it takes place), the meeting type (onboarding, initial, follow-up, final) and optionally the protocol to run. Only pending meetings can be rescheduled.

Running a call

  1. Open the appointment — from Communications, the Calendar, the client's timeline or the dashboard — and press Start call. The platform places the call to the caregiver's phone through Twilio.
  2. Work through the protocol questions in the Protocols tab, recording answers as you go. Answers save themselves as you type, and the panel tells you when it last saved.
  3. Use the Notes tab for anything the protocol has no question for. It autosaves the same way.
  4. If the call is not answered you can Send reminder to the caregiver on WhatsApp — attempts are counted.
  5. Press End call and set the outcome (complete, interrupted, not answered). You stay exactly where you were.
Tip
Start call is greyed out, with an explanation, unless both you and the caregiver have a phone number on file. Fill those in under the client and your own profile.

Calling it off

A call that has not happened yet can be cancelled from the panel footer, with a reason. It leaves the queue but stays in the history, struck through, and can be put back. A call that already happened keeps its outcome — that is never overwritten. See Communications for the detail.

After the call

  • Recordings — call recordings are fetched from Twilio and attached to the meeting (admins can trigger a fetch under Settings → Maintenance).
  • Transcribe — turn a recording into text with one click; Re-transcribe replaces it.
  • Summaries — generate a transcript summary and a protocol summary for the meeting. The prompts behind these are configurable by admins (Settings → Prompts).
Heads-up
Starting calls needs the Twilio integration configured (an admin task), and the caregiver's number must be valid — the platform will tell you if a WhatsApp reminder can't be delivered.
