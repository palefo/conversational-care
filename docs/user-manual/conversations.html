Conversations & chat

Read what clients and agents said — on WhatsApp, SMS or web chat — and improve it with feedback.

Clients and caregivers talk to their agent over WhatsApp, SMS, or a web chat with voice. Your team can read every conversation, listen to voice messages, and teach the system with feedback.

Reading a conversation

Conversations are grouped by day — a day's chat is one item. Open one from Communications, from the dashboard, or from a chat entry in the client's timeline. It opens in the detail panel, with Summary and Conversation tabs: the summary is what you read first, the transcript is there when you need it. Voice messages appear with a player; agent voice replies too.

Unread conversations are shown in bold, and opening one marks it read for you. From the client's timeline you can still step through days one at a time.

Each day's conversation is analysed automatically (a note shows if the analysis is still pending) and can be summarised for quick review.

Giving feedback

Feedback improves both the agents and the alerting. On any conversation you can:

  • Rate the conversation — a score out of five for how the agent handled it as a whole.
  • Say what was good or wrong — a written note, for the things a score cannot carry.
  • Confirm what actually came up — the agent flags topics automatically; your yes/no on each is what it gets measured against. An agent with no detectors configured shows no flags here.

The test chat

Every client can have one test user (created by an admin on the Users page). Signing in as the test user opens the same chat experience the client gets — including voice — wired to that client's agent. Use it to try a new agent or prompt before real people rely on it.

Recording voice in the browser needs a secure (HTTPS) connection and microphone permission — the chat will guide you if either is missing.

WhatsApp specifics

  • Messages are answered by the client's agent automatically; if the reply takes time (transcription, text-to-speech), the platform acknowledges Twilio immediately and sends the answer as soon as it is ready.
  • Voice-note replies can be enabled platform-wide by an admin (Enable WhatsApp audio in Settings).
