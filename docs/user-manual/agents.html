Agents

Configure the AI assistants that power every chat surface.

Admin

Agents are the AI assistants behind every chat surface — the client chat, the WhatsApp conversations, the navigator assistant bubble. The Agents page lets admins create, configure and test them.

Three kinds

KindWhat it isYou manage
Prompt-basedRuns inside the platform, driven by a system prompt you write. No tools.Create, edit, delete. The prompt and the model.
RemoteConnects to an agent running on your own LangGraph server (host:port).Create, edit, delete. The connection details.
NativeShips with the platform (e.g. Loopback, the navigator assistant, self-registration).Edit only: the model and voice they use.

Creating and editing

  • Every agent has a name, a model (blank = the platform default; prefix with a provider, e.g. anthropic/claude-sonnet-4-6), and optionally a voice for spoken replies.
  • Prompt-based agents store the system prompt used on every turn — write it as instructions to the assistant.
  • Remote agents point at an allow-listed host — your platform admin controls the allow-list (a security guard).
  • Advanced: conversation classification — configure how the agent's conversations are summarised and flagged for human review.

Testing

Every agent has a Test button that opens a private chat (text and audio) wired to just that agent — nothing is saved. Use it after any prompt or model change.

Assigning agents

Each client points at one agent (chosen when creating or editing the client) — that agent handles their WhatsApp/web conversations and the test-user chat.

Tip
Loopback simply echoes what it receives — handy as a safe placeholder and for checking connectivity end-to-end before pointing a client at a real agent.
